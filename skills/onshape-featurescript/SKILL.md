# Onshape FeatureScript — Custom Feature Authoring Guide

FeatureScript is Onshape's open-source procedural language used to create native parametric features. Every built-in feature (extrude, revolve, fillet) in Onshape runs on FeatureScript.

> [!TIP]
> **API Quota Efficiency**
> Rather than calling 15-20 individual REST API endpoints to sketch, extrude, revolve, cut, and fillet a multi-step part, authoring a single **FeatureScript custom feature** compiles and generates all geometry in **1 single API call** (`write_featurescript_feature`). This is critical for staying within the account's 2,500 annual API limit.

---

## 1. Preamble & Imports

Every FeatureScript file **must** declare the version and import the standard geometry library:

```featurescript
FeatureScript 2931;
import(path : "onshape/std/geometry.fs", version : "2931.0");
```

---

## 2. Standard Boilerplate Structure

A custom feature consists of:
1. `annotation { "Feature Type Name" : "Display Name" }`
2. `export const featureIdentifier = defineFeature(function(context is Context, id is Id, definition is map)`
3. A `precondition` block declaring user-editable parameters.
4. An execution body invoking standard `op*` and `sk*` functions.

```featurescript
FeatureScript 2931;
import(path : "onshape/std/geometry.fs", version : "2931.0");

annotation { "Feature Type Name" : "My Parametric Part" }
export const myParametricPart = defineFeature(function(context is Context, id is Id, definition is map)
    precondition
    {
        annotation { "Name" : "Outer Diameter" }
        isLength(definition.outerDiameter, LENGTH_BOUNDS);

        annotation { "Name" : "Total Length" }
        isLength(definition.totalLength, LENGTH_BOUNDS);

        annotation { "Name" : "Wall Thickness" }
        isLength(definition.wallThickness, LENGTH_BOUNDS);

        annotation { "Name" : "Hollow Out" }
        definition.isHollow is boolean;
    }
    {
        // Feature implementation code goes here
    });
```

## 3. UI Precondition Parameter Types

Declare inputs within `precondition` using standard bounds and predicates:

| Parameter Type | Declaration | Example |
| :--- | :--- | :--- |
| **Length** | `isLength(definition.paramName, LENGTH_BOUNDS);` | Dimensions in mm / in |
| **Angle** | `isAngle(definition.paramName, ANGLE_BOUNDS);` | Sweep angles, tapers |
| **Real / Float** | `isReal(definition.paramName, POSITIVE_REAL_BOUNDS);` | Ratios, pitch multipliers |
| **Integer** | `isInteger(definition.paramName, POSITIVE_COUNT_BOUNDS);` | Hole counts, fin counts |
| **Boolean** | `definition.paramName is boolean;` | Checkboxes (toggles) |
| **Entity Query**| `annotation { "Filter" : EntityType.FACE } definition.targetFace is Query;` | Selected faces/edges |

## 4. Unit Handling Discipline (Crucial)

Onshape internally computes all lengths in **meters** and angles in **radians**.
- Raw numbers in math functions (`sin()`, `cos()`, `sqrt()`) will produce errors or silent failures if units are not explicitly stripped.

**The Golden Pattern:**
1. **Strip units** before mathematical operations:
   ```featurescript
   const lengthM = definition.totalLength / meter;
   const diamM = definition.outerDiameter / meter;
   ```
2. **Perform trig / algebraic calculations**:
   ```featurescript
   const radiusM = diamM / 2.0;
   const taperAngleRad = atan2((baseRadiusM - tipRadiusM), lengthM);
   ```
3. **Re-apply unit constants** when passing to vectors, points, planes, or operations:
   ```featurescript
   const centerPoint = vector(0, 0, lengthM) * meter;
   ```

## 5. Geometry Tracking & Query Patterns

In FeatureScript, you track geometry using queries and IDs rather than hardcoded names.

### Common Query Functions:
- **`qCreatedBy(id + "opName", EntityType.BODY)`**: Targets bodies created by a specific operation.
- **`qCreatedBy(id + "opName", EntityType.FACE)`**: Targets faces created by a specific operation.
- **`qGeometry(query, GeometryType.PLANE)`**: Filters a set of faces to only planar faces.
- **`qGeometry(query, GeometryType.CYLINDER)`**: Filters to cylindrical faces (e.g. bores, shafts).
- **`qSketchRegion(id + "sketchName")`**: Grabs the closed profile face generated by a sketch.
- **`qAllNonMeshSolidBodies()`**: Selects all active solid bodies in the Part Studio.
- **`qSubtraction(queryA, queryB)`**: Set difference between two query sets.
- **`qUnion([queryA, queryB])`**: Combines query sets.
- **`qLargest(query)`**: Selects the entity with the largest area/length.

## 6. Sketching Inside FeatureScript

To sketch inside FeatureScript:
1. Create a sketch with `newSketchOnPlane`:
   ```featurescript
   var sketch = newSketchOnPlane(context, id + "sketch1", {
       "sketchPlane" : plane(vector(0, 0, 0) * meter, vector(0, 0, 1), vector(1, 0, 0))
   });
   ```
2. Add sketch primitives:
   - Line: `skLineSegment(sketch, "line1", { "start" : vector(0, 0) * meter, "end" : vector(40, 0) * millimeter });`
   - Circle: `skCircle(sketch, "circle1", { "center" : vector(0, 0) * meter, "radius" : 10 * millimeter });`
   - Rectangle: `skRectangle(sketch, "rect1", { "firstCorner" : vector(-10, -10) * millimeter, "secondCorner" : vector(10, 10) * millimeter });`
3. Solve the sketch:
   ```featurescript
   skSolve(sketch);
   ```

## 7. Proven Recipes

### A. Revolve Operation (Axially Symmetric Fuze Bodies / Casings)
```featurescript
opRevolve(context, id + "revolve1", {
    "entities" : qSketchRegion(id + "profileSketch"),
    "axis"     : line(vector(0, 0, 0) * meter, vector(0, 0, 1)), // Z axis
    "angleForward" : 360 * degree
});
```

### B. Helical Sweep (External / Internal Threads & Springs)
Avoid `opHelix` (known to produce obscure REGEN_ERRORs). Use `opFitSpline` + `opSweep`:
```featurescript
// 1. Sample helical points
var pts = [];
for (var i = 0; i < nPts; i += 1) {
    const t = i / (nPts - 1);
    const z = zStart + t * totalLen;
    const theta = -2 * PI * turns * t; // negative for right-handed
    pts = append(pts, vector(r * cos(theta), r * sin(theta), z) * meter);
}
opFitSpline(context, id + "helixPath", { "points" : pts });

// 2. Sketch thread profile on normal plane at start
var profile = newSketchOnPlane(context, id + "threadProfile", {
    "sketchPlane" : plane(vector(0, 0, zStart) * meter, vector(0, -1, 0), vector(1, 0, 0))
});
skLineSegment(profile, "l1", { "start" : vector(r - depth, 0) * meter, "end" : vector(r, width/2) * meter });
skLineSegment(profile, "l2", { "start" : vector(r, width/2) * meter,   "end" : vector(r, -width/2) * meter });
skLineSegment(profile, "l3", { "start" : vector(r, -width/2) * meter,  "end" : vector(r - depth, 0) * meter });
skSolve(profile);

// 3. Sweep along fitted spline
opSweep(context, id + "threadSweep", {
    "profiles" : qSketchRegion(id + "threadProfile"),
    "path"     : qCreatedBy(id + "helixPath", EntityType.EDGE)
});

// 4. Subtract from host body
opBoolean(context, id + "threadCut", {
    "tools"         : qCreatedBy(id + "threadSweep", EntityType.BODY),
    "targets"       : qCreatedBy(id + "hostBody", EntityType.BODY),
    "operationType" : BooleanOperationType.SUBTRACTION
});
```

## 8. Invoking from the MCP Tool Layer

Call `write_featurescript_feature` from the MCP client:

```json
{
  "documentId": "<doc_id>",
  "workspaceId": "<workspace_id>",
  "elementId": "<part_studio_id>",
  "feature_type": "myParametricPart",
  "feature_name": "PGK Casing Assembly",
  "feature_script": "<full FeatureScript code>",
  "parameters": [
    {"id": "outerDiameter", "type": "quantity", "value": "80 mm"},
    {"id": "totalLength",   "type": "quantity", "value": "220 mm"},
    {"id": "wallThickness", "type": "quantity", "value": "4 mm"},
    {"id": "isHollow",      "type": "boolean",  "value": true}
  ]
}
```
The server automatically creates the Feature Studio, uploads the source code, binds the namespace, applies the feature to your Part Studio, and returns the regen status and geometric diff.
